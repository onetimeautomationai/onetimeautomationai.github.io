Set Up Herdr and Run Your First Agents

One install line, then the steps from my walkthrough, in order.

Paste into your terminal 
curl -fsSL https://herdr.dev/install.sh | sh

Launch and build your first space

  1. Launch it. After the install finishes, type herdr in your terminal. Herdr opens inside the terminal.
  2. Understand the layout. Spaces hold tabs, tabs hold panes, and every pane is one agent.
  3. Create a space. Add a new space. The mouse works inside Herdr, so you can click between spaces. Right-click a space to rename it.
  4. Split it into panes. Split the tab until you have four panes. Each pane is its own terminal.
  5. Start an agent in each pane. Type the name of your AI agent, for example claude, and give it a task. The pane you click highlights in orange, so you always know which agent you are talking to.
  6. Add a second tab. Click add tab and start four more agents. That is eight agents in one space while you keep working.
  7. Close what you finish. Use close pane when an agent is done, then start a fresh one in its place.

Close it, reboot it, come back

Herdr is persistent. If you close the window or reboot your computer, run herdr again and it takes you back to where you left off.

Good to know: Herdr is a terminal app, so you need a terminal. The install script from herdr.dev supports Mac and Linux. It puts the program in ~/.local/bin by default. Full install notes are in the docs at herdr.dev.
