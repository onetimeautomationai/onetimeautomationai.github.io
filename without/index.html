The Without-Me Worksheet

The four questions I run on any task that still depends on me, before I decide whether it needs a person, a written rule, or an agent.

Pick the one task that stops dead the moment you go quiet. Run it through these four questions, in order. Don't skip to the end.

Not "who could do this." That question always ends with you deciding nobody could. These four ask something different, and the answer is usually smaller than you think.

01

What would have to be true for this to happen without me?

Name the actual conditions, not a person's name. Most of the time it's one written rule and one decision made once, not a hire.

Write it down: the smallest thing that has to exist before this can run without you touching it.
02

What does "good" look like, specific enough that someone else could tell without asking me?

You know good when you see it. That's the problem. Nobody else can see it, because it has only ever lived in your head.

Write it down: the finished result in plain terms, not how you'd do it, how anyone would know it worked.
03

What is the one moment this should stop and wait for me?

Be strict here. Most tasks have zero or one real exception, not five. If you can't name it, you're not delegating, you're still hovering.

Write it down: the exact trigger that routes back to you. Everything else is allowed to run without asking.
04

What is actually going to carry it, once the first three are answered?

A rule with nobody and nothing running it is still your task. This is the question that turns a worksheet into a working machine.

Decide now: a person, a written checklist, or an agent. Then hand it over this week, not when things calm down.

Being the bottleneck feels good. Every ping is proof you're needed. That's exactly why most people never run this worksheet on the task that costs them the most, they run it on the easy ones instead.
